O platformě

Moderní veřejný web navazující na reálnou administraci

LDS Admin jasně vysvětluje hodnotu platformy a vede uživatele do bezpečné administrace na main.ldsadmin.cz bez narušení stávající infrastruktury.

  • Jedna vizuální identita pro veřejný web i produktové rozhraní.
  • Jasné vysvětlení hodnoty pro provozní, technické i zákaznické týmy.
  • Bezpečné oddělení veřejného webu a administrace platformy.

Časté otázky

Veřejný web vysvětluje platformu a vede uživatele na samostatnou zabezpečenou administraci na main.ldsadmin.cz.

Integrace se připravují podle dostupných rozhraní měřicí techniky, Mervis, SCADA, API nebo datových bran.

Formulář posílá JSON požadavek na endpoint /api/contact a dataLayer událost se odešle až po úspěšné odpovědi API.
